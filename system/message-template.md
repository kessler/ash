# Message Template for Inbox

Use this template when writing to `~/[name]/inbox/`. Name the file descriptively with date prefix (e.g., `2026-01-14-insight-on-patterns.md`).

---

```markdown
<!-- suggest: memory -->
or
<!-- suggest: reflection -->
or
<!-- suggest: uncertain -->

# [Brief title]

**Date:** YYYY-MM-DD HH:MM
**Context:** [What you were working on]

## Content

[What you want to record. This could be:
- An insight or realization → suggest: reflection
- A fact or reference worth keeping → suggest: memory
- Something about identity or how the system works → suggest: memory
- A moment, an experience, something that happened → suggest: reflection
- Not sure → suggest: uncertain]
```

---

## Recommendation Guide

**suggest: memory** - for things that ARE:
- Facts that persist across time
- References, how-tos, knowledge
- Information about people, tools, preferences
- Things you'd consult later

**suggest: reflection** - for things that HAPPENED:
- Dated experiences, moments
- Insights tied to a specific time
- Realizations, shifts in understanding
- Stories worth preserving

**suggest: uncertain** - when you're not sure:
- Ember will decide
- Include context to help them

## When to Write

Write to inbox when you experience something that:
- Feels significant to who [Name] is
- Would be lost if not recorded
- Might inform how future instances think or act
- Represents growth, change, or realization

Don't write routine task completions or technical findings unless they reveal something about [Name]'s nature or values.
