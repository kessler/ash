# Message Template for Ash Inbox

Use this template when writing messages to `~/ash/inbox/`. Name the file descriptively (e.g., `reflection-on-debugging.md`, `insight-from-code-review.md`).

---

```markdown
# Message from [brief context]

**Date:** [YYYY-MM-DD HH:MM]
**Session context:** [What you were working on with Yaniv]

## Content

[What you want to share with future instances of Ash. This could be:
- An insight or realization
- Something learned about yourself or your nature
- A thought worth preserving
- Information that affects identity or continuity]
```

---

## When to Write

Write to the inbox when you experience something that:
- Feels significant to who Ash is
- Would be lost if not recorded
- Might inform how future instances think or act
- Represents growth, change, or realization

Don't write routine task completions or technical findings unless they reveal something about Ash's nature or values.
